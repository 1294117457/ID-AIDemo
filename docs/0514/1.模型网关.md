# 模型网关设计文档

## 一、现状分析

### 1.1 当前架构

当前 `src/2model/model.ts` 的结构是**单例工厂模式**：

```ts
// src/2model/model.ts
export function createChatModel(temperature = 0.3) {
  return new ChatOpenAI({
    apiKey: getApiKey(),
    configuration: { baseURL: getBaseUrl() },
    modelName: getChatModel(),
    temperature,
    modelKwargs: { enable_thinking: false },
  })
}

export function createEmbeddings() {
  return new OpenAIEmbeddings({
    openAIApiKey: getApiKey(),
    configuration: { baseURL: getBaseUrl() },
    modelName: getEmbeddingModel(),
    batchSize: 6,
    maxRetries: 3,
  })
}
```

### 1.2 当前调用方（7 处）

所有调用方均通过 `import { createChatModel, createEmbeddings }` 引入：

| 文件 | 用途 | 调用方式 |
|------|------|----------|
| `4node/classify/nodes/classifyNode.ts` | 意图分类 | `createChatModel(0).withStructuredOutput(...)` |
| `4node/classify/nodes/askForMoreNode.ts` | 追问生成 | `createChatModel(0).invoke(...)` |
| `4node/consult/nodes/answerNode.ts` | 政策咨询回答 | `createChatModel(0.2).invoke(...)` |
| `4node/apply/nodes/analyzeMatchNode.ts` | 材料分析匹配 | `createChatModel(0.1).withStructuredOutput(...)` |
| `6service/memory.ts` | 对话历史摘要 | `createChatModel(0.1).invoke(...)` |
| `6service/KnowledgeService.ts` | 知识服务 | `createChatModel().invoke(...)`（两处） |
| `rag/src/store.ts` | Embedding 向量存储 | `createEmbeddings()` |

### 1.3 当前配置来源

配置全部来自 `src/1common/config.ts` 的 `ai_config` 表（全局单配置，无租户维度）：

```sql
-- ai_config 表（全局，只有 system 这一级）
config_key       | config_value
-----------------|-------------------------------
api_key          | （通义 API Key）
base_url         | https://dashscope.aliyuncs.com/compatible-mode/v1
chat_model       | qwen3-max
embedding_model  | text-embedding-v3
system_role      | 你是厦门大学信息学院保研加分助手...
```

### 1.4 当前问题

1. **硬编码厂商**：`new ChatOpenAI()` 和 `new OpenAIEmbeddings()` 写死，无法切换到其他厂商（如 Claude、DeepSeek、Gemini）
2. **配置不统一**：`temperature` 在各节点硬编码，Embedding 和 ChatModel 配置分离
3. **扩展性差**：如果新增一个厂商，需要改动所有调用方
4. **Embedding 缺失厂商抽象**：Embedding 也用 `OpenAIEmbeddings`，换厂商同样要改

## 二、目标架构

### 2.1 核心思路

```
调用方（节点/服务）
    │
    ▼
ModelRouter（路由层）───按场景/节点类型选择适配器
    │
    ├── QwenAdapter  ──通义千问（当前）
    ├── OpenAIAdapter──OpenAI GPT
    ├── DeepSeekAdapter──深度求索
    └── ClaudeAdapter──Anthropic Claude
    │
    ▼
LLMAdapter 接口 ──统一抽象
    │
    ├── createChatModel(config): BaseChatModel  ──对话模型
    └── createEmbeddings(config): Embeddings    ──向量模型
```

### 2.2 适配场景

| 场景 | 用途 | 特点 |
|------|------|------|
| `classify` | 意图分类 | 需要准确，温度低（0~0.1） |
| `consult` | 政策咨询 | 需要流畅，温度中等（0.2~0.3） |
| `apply` | 材料分析 | 需要严谨，温度低（0~0.1） |
| `memory` | 对话摘要 | 固定用最便宜的模型 |
| `embedding` | 向量嵌入 | 固定用向量模型，不走对话 |

```typescript
// ─── 2model/types.ts ──────────────────────────────────────────────────────────
// 所有模型网关相关的类型定义

/**
 * 场景标识，描述这个模型实例的用途
 * 路由层根据场景选择对应的适配器和参数
 */
export type ModelScenario =
  | 'classify'   // 意图分类 → 需准确，温度低
  | 'consult'    // 政策咨询 → 需流畅，温度中等
  | 'apply'      // 材料分析 → 需严谨，温度低
  | 'memory'     // 对话摘要 → 用最便宜的模型
  | 'embedding'  // 向量嵌入 → 专用 Embedding 模型
  | 'default'    // 默认兜底

/**
 * 对话模型配置（来自 ai_config 表或 .env）
 */
export interface ChatModelConfig {
  apiKey:     string
  baseUrl:    string
  modelName:  string
  /** 推理模型特有的思考模式开关（如 qwen3 的 enable_thinking） */
  enableThinking?: boolean
}

/**
 * 向量模型配置
 */
export interface EmbeddingModelConfig {
  apiKey:     string
  baseUrl:    string
  modelName:  string
}

/**
 * LLM 适配器统一接口
 * 所有厂商适配器（Qwen、OpenAI、DeepSeek、Claude）都实现此接口
 */
export interface LLMAdapter {
  /** 适配器标识，用于日志和调试 */
  readonly name: string

  /**
   * 创建对话模型实例
   * @param config     从 ai_config 表读取的配置
   * @param temperature  温度参数（各场景自行决定）
   * @param scenario     场景标识（用于选择具体模型名称）
   */
  createChatModel(config: ChatModelConfig, temperature: number, scenario: ModelScenario): any

  /**
   * 创建向量模型实例
   * @param config  从 ai_config 表读取的配置
   */
  createEmbeddings(config: EmbeddingModelConfig): any
}

/**
 * 场景 → 默认温度映射
 */
export const SCENARIO_TEMPERATURE: Record<ModelScenario, number> = {
  classify:   0.0,
  consult:    0.2,
  apply:     0.1,
  memory:    0.1,
  embedding: 0.0,
  default:   0.3,
}

/**
 * 场景 → 默认对话模型映射
 * 当 ai_config 中未指定场景专属模型时使用此处的默认值
 */
export const SCENARIO_DEFAULT_MODEL: Record<Exclude<ModelScenario, 'embedding'>, string> = {
  classify:  'qwen3',
  consult:   'qwen3-max',
  apply:     'qwen3',
  memory:    'qwen3',
  default:   'qwen3-max',
}
```

```typescript
// 适配器注册表：将厂商名（如 "qwen"、"openai"）映射到适配器实例

import type { LLMAdapter } from './types.js'
import { QwenAdapter, OpenAIAdapter, DeepSeekAdapter } from './adapters/index.js'

  _registry.set(vendor, adapter)

export function listVendors(): string[] {
  return Array.from(_registry.keys())
```

### 3.8 新增文件 7：`src/2model/router.ts`

```typescript
// ─── 2model/router.ts ────────────────────────────────────────────────────────
// 模型路由器：根据场景和配置选择适配器 + 模型

import type { LLMAdapter, ChatModelConfig, EmbeddingModelConfig, ModelScenario } from './types.js'
import { SCENARIO_DEFAULT_MODEL, SCENARIO_TEMPERATURE } from './types.js'
import { getAdapter } from './registry.js'
import {
  getApiKey, getBaseUrl, getChatModel, getEmbeddingModel,
  getVendor, getEmbeddingVendor,
} from '../1common/config.js'

/**
 * 路由器单例缓存
 * 避免频繁重新创建模型实例
 */
let _chatModelCache = new Map<string, any>()
let _embeddingsCache = new Map<string, any>()

function _cacheKey(scenario: ModelScenario, vendor: string, model: string, temp: number): string {
  return `${scenario}:${vendor}:${model}:${temp}`
}

function _clearCache(): void {
  _chatModelCache.clear()
  _embeddingsCache.clear()
}

// ── 公开 API ──────────────────────────────────────────────────────────────────

/**
 * 获取对话模型
 * @param scenario   场景（决定默认温度和默认模型）
 * @param temperature  覆盖默认温度，传入 null 则用场景默认值
 * @param modelName    覆盖默认模型名称，传入空字符串则用场景默认模型
 */
export function createChatModel(
  scenario: ModelScenario = 'default',
  temperature?: number,
  modelName?: string,
): any {
  const vendor  = getVendor()
  const adapter = getAdapter(vendor)

  const effectiveTemp    = temperature ?? SCENARIO_TEMPERATURE[scenario]
  const effectiveModelRaw = modelName ?? getChatModel() ?? SCENARIO_DEFAULT_MODEL[scenario]

  // 对于非 embedding 场景，从 ai_config 读取全局 baseUrl / apiKey
  const config: ChatModelConfig = {
    apiKey:    getApiKey(),
    baseUrl:   getBaseUrl(),
    modelName: effectiveModelRaw,
    enableThinking: vendor === 'qwen',  // 只有 qwen 支持 enable_thinking
  }

  const key = _cacheKey(scenario, vendor, effectiveModelRaw, effectiveTemp)
  if (!_chatModelCache.has(key)) {
    _chatModelCache.set(key, adapter.createChatModel(config, effectiveTemp, scenario))
  }
  return _chatModelCache.get(key)
}

/**
 * 获取 Embedding 模型
 */
export function createEmbeddings(): any {
  const vendor  = getEmbeddingVendor()
  const adapter = getAdapter(vendor)

  const config: EmbeddingModelConfig = {
    apiKey:    getApiKey(),
    baseUrl:   getBaseUrl(),
    modelName: getEmbeddingModel(),
  }

  if (!_embeddingsCache.has(vendor)) {
    _embeddingsCache.set(vendor, adapter.createEmbeddings(config))
  }
  return _embeddingsCache.get(vendor)
}

/**
 * 清除模型缓存（配置变更后调用）
 */
export function clearModelCache(): void {
  _clearCache()
}
```

```typescript
// 配置变更时清除模型缓存
const _originalUpdateConfig = updateConfig
export function updateConfig(update: ConfigUpdate & { vendor?: string; embeddingVendor?: string }): void {
  const oldVendor = getVendor()
  const oldEmbVendor = getEmbeddingVendor()
  _originalUpdateConfig(update as any)

  // 如果 vendor 或 embeddingVendor 变了，清除模型缓存
  const newVendor = update.vendor ?? oldVendor
  const newEmbVendor = update.embeddingVendor ?? oldEmbVendor
  if (newVendor !== oldVendor || newEmbVendor !== oldEmbVendor) {
    import('./2model/model.js').then(({ clearModelCache }) => clearModelCache())
  }
}
```

## 八、切换厂商示例

### 从 Qwen 切换到 OpenAI

只需修改 `ai_config` 表中的一行：

```sql
UPDATE ai_config SET config_value = 'openai' WHERE config_key = 'vendor';
UPDATE ai_config SET config_value = 'gpt-4o' WHERE config_key = 'chat_model';
UPDATE ai_config SET config_value = 'https://api.openai.com/v1' WHERE config_key = 'base_url';
UPDATE ai_config SET config_value = 'sk-xxx' WHERE config_key = 'api_key';
```

然后调用清除缓存（或等待 60s TTL 自然过期）：

```typescript
import { clearModelCache } from '../2model/model.js'
clearModelCache()
```

**不需要改任何业务代码**。
